# 日课 · DAYLIST

一个很小、很安静的每周日程规划页。

## 使用

双击 `start.command`，浏览器会打开 <http://127.0.0.1:4173/>。  
也可以直接打开 `index.html`，不需要安装任何依赖。

手动启动本地服务：

```bash
cd daylist
python3 -m http.server 4173 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:4173/
```

## 功能

- 选择星期，按 24 小时制分别键入开始与结束的时、分，填写活动后加入当周日程
- 键入两位小时/分钟后自动跳到下一格
- 周一至周日形成一张周表，按每天的先后时间自动排序
- 一键打卡 / 取消完成，左侧同步本日完成与本周完成进度
- 删除录错的活动
- 选中某天后，星期旁边的两个图标可复制 / 清除当天日程
- 复制：点复制图标后，直接点目标日标题；追加到目标日，完成状态重置，重复日程自动跳过
- 清除：一键清空当天，底部提示条提供撤销
- 切换上一周 / 下一周，每一周的日程独立保存
- 自动保存到浏览器本机，刷新、关页、切周都不丢
- 窄屏适配

没有账号、分类、统计、通知或云端同步。
